# FlyLife Freebies

Interaktive Web-Freebies für das FlyLife-Projekt. Aktuell liegt hier insbesondere **„Der Ausstiegs-Check · Bleiben oder gehen?“** als eigenständige statische HTML-Anwendung.

## Aktuelle Dateien

- `ausstiegs-check.html` — interaktiver Ausstiegs-Check als Single-File-Web-App

## Entwicklung

Die App ist statisch und benötigt keinen Build-Schritt. Änderungen werden direkt an der HTML-Datei vorgenommen und anschließend im Browser sowie mobil geprüft.
